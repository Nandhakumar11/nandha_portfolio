### 🔒 CAN Bus Intrusion Detection System — Transformer-Based Deep Learning
`Python` `NumPy` `scikit-learn` `Matplotlib` `GitHub` `HTML/CSS/JS` `Chart.js`

> *Capstone Project — Machine Learning | Winter 2026 | Conestoga College*

Modern vehicles rely on the **Controller Area Network (CAN) bus** for real-time ECU communication — a protocol with no built-in authentication, making it vulnerable to injection attacks. This project builds an **Intrusion Detection System (IDS)** using a Transformer-based deep learning model to classify CAN frames as normal or attack traffic.

**Key highlights:**
- Implemented a full **Transformer encoder from scratch in pure NumPy** (no PyTorch/TensorFlow) — including scaled dot-product attention, sinusoidal positional encoding, and layer normalisation.
- Trained on the **HCRL Car-Hacking Dataset** (Korea University), achieving **97.25% accuracy** and **AUC-ROC of 0.992** on the test partition.
- Built a fully browser-based **interactive explainability dashboard** featuring training curves, ROC/PR curves, confusion matrix, attention heatmaps, and per-frame confidence scores — all running client-side with Chart.js.
- Coordinated Agile task tracking on GitHub across a 3-person team.

**Results summary:**

| Class | Precision | Recall | F1-Score | AUC-ROC |
|---|---|---|---|---|
| Normal | 0.997 | 0.971 | 0.984 | 0.992 |
| Fuzzy | 1.000 | 0.977 | 0.988 | 0.981 |
| DoS | 0.182 | 1.000 | 0.308 | 0.965 |
| **Macro avg** | **0.547** | **0.990** | **0.629** | **0.968** |
